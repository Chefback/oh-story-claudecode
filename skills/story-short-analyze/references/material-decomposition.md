## 短篇 vs 长篇：本质差异

| 维度 | 长篇 | 短篇 |
|------|------|------|
| 篇幅 | 数十万字、数百章 | 5000-15000字、6-12节 |
| 弧线 | 多线交织、多卷结构 | 单弧线、压缩三幕 |
| 角色 | 群像、分级体系 | 精简（3-5人）、功能高度浓缩 |
| 世界观 | 复杂设定、力量体系 | 现实为主、极少特殊设定 |
| 核心驱动 | 爽点循环、升级感 | 情绪炸弹、反转冲击 |
| 读者粘性 | 追更驱动 | 一口气读完 |
| 分析重心 | 结构完整性、伏笔管理 | 情绪设计、技法运用、节奏密度 |

**核心信念：短篇的本质是情绪炸弹。拆文就是拆弹——看它用什么引信、什么火药、什么时间引爆。**

## 拆解流程 6 阶段

> **编号说明**：Phase 1（确认拆解对象+题材路由）由 SKILL.md 处理，无需方法论文件。本文件从 Phase 2 开始编号。

### Phase 2：结构识别 + 节拍提取

- 识别章节/小节分隔符（###01、第一章、01 等）
- 提取标题，记录每节字数
- 识别 POV（第一/第三人称、全知视角）
- 识别叙事时间线（线性/插叙/倒叙/双线交叉）

将全文划分为功能段（铺垫/发展/转折/高潮/收尾），标注每段字数范围和占比。

#### B. 节拍提取（每节 3-8 个）

节拍 = 最小的情绪/叙事单位，由一个具体事件或信息释放构成。

密度公式：每 {200-300 字} 一个节拍，每节 3-8 个，全文 15-60 个。

| 全文字数 | 目标节拍数 | 说明 |
|----------|-----------|------|
| ≤5000 | 15-25 个 | 精短型，每个节拍必须有效 |
| 5000-8000 | 25-40 个 | 标准型 |
| 8000-12000 | 35-55 个 | 中长型 |
| >12000 | 45-60 个 | 长短篇（上限） |

每个节拍提取：

| 字段 | 说明 |
|------|------|
| 序号 | 严格时间顺序 |
| 类型 | 情绪节拍/信息节拍/冲突节拍/转折节拍/对话节拍/氛围节拍 |
| 描述 | 客观白描，只记录发生了什么（禁止叙事框架词） |
| 原文引用 | ≤300 字直接引用 |
| 情绪标记 | 情绪类型 + 强度（-9 到 +9） |
| 涉及人物 | 全名 |
| 技法标记 | 使用了什么技法（如有时） |

### Phase 3：情绪架构分析

#### A. 情绪曲线

从节拍数据生成情绪曲线。每个节拍的情绪标记连接成曲线。节点数 = 至少 max(5, 节数) 个，确保每节至少有一个情绪节点。

曲线特征提取：
- 起始情绪
- 走向模式（上行/下行/波浪/V形/倒V/阶梯/断崖/压缩弹簧）
- 极值（最高点、最低点及其位置百分比）
- 方向差（起始到结尾的净变化）
- 翻转次数（正负交替次数）

#### B. 情绪炸弹分析

短篇的情绪设计如同炸弹，拆解其构造：

| 组件 | 问题 |
|------|------|
| 引信 | 什么让读者开始在意？前多少字完成？ |
| 火药 | 什么在积累情绪势能？积累多久？ |
| 延时装置 | 有没有延迟引爆？信息差/误解/悬念？ |
| 引爆点 | 哪个瞬间释放全部情绪？精确到句子 |
| 弹片 | 释放后有没有余波？多个角色反应？ |
| 弹坑 | 情绪释放后留下什么？读者记住什么？ |

#### C. 期待管理追踪

逐节追踪读者的期待状态：

| 节 | 制造的期待 | 满足/升级/悬置 | 剩余期待 |
|----|-----------|---------------|---------|
| 1 | {期待A} | {制造} | {A} |
| 2 | {期待B} | {升级A} | {A+, B} |
| ... | | | |

期待管理规则：「两长一短不断」——不超过两节不制造新期待，不超过一节不推进核心期待。

### Phase 4：反转 + 技法分析

#### A. 反转分析

**前置反转检查**：是否有在故事时间线之前就已存在的谎言/误判。

**反转机制拆解**：
- 铺垫线索（≥2条，含原文位置）
- 误导方向（作者把读者往哪引）
- 真相揭示（怎么揭开的）
- 合理性（回看得不失真）
- 时机（全文百分之几位置）
- 铺放比（铺垫字数 : 释放字数）

#### B. 技法分析

逐项分析以下技法维度的使用情况：

| 维度 | 分析内容 |
|------|----------|
| POV策略 | 人称选择的效果、叙事距离、可靠性 |
| 对话技法 | 密度比、潜台词率、审判式对话、信息差对话 |
| 时间操控 | 时间跳跃、场景压缩、平行剪辑 |
| 信息控制 | 读者知道 vs 角色知道、隐瞒/揭示时机 |
| 感官锚定 | 五感分布、主导感官、感官切换节奏 |
| 句式节奏 | 长短句交替、节奏加速/减速、关键句位置 |
| 对比锚点 | 角色对比、前后对比、环境对比 |
| 意象/物件 | 重复出现的物件、意象、象征 |
| 留白技法 | 不写之写、省略的艺术、暗示 |

每项技法标注：使用位置、效果评价、可借鉴点。

### Phase 5：角色 + 首尾分析

#### A. 角色提取

短篇角色精简（通常 3-5 人），但每个人物承担多重功能。

| 字段 | 说明 |
|------|------|
| 姓名 | 全名 |
| 功能标签 | 情绪承载者/压迫源/反转触发器/道德锚点/对照组/催化剂 |
| 内在矛盾 | 核心心理冲突（不是外部遭遇） |
| 一句话画像 | 从行为归纳，不从标签推导 |
| 关键对白 | 最能代表该角色的 1-2 句台词 |
| 弧线 | 始→转→终（标注触发事件和位置）。无明显弧线标注"扁平" |
| 情绪功能 | 在情绪架构中承担什么角色 |

#### A2. 角色关系提取

从节拍数据中提取角色间的关系和演变：

| 字段 | 说明 |
|------|------|
| 关系对 | A ↔ B（全名） |
| 关系本质 | 一句话概括关系核心（如：单向依附→对等拒绝） |
| 演变轨迹 | 节N:状态A → 节M:状态B，标注触发事件 |
| 情绪贡献 | 这段关系对情绪架构的贡献（制造了什么情绪） |

提取策略：
- 只提取有直接互动或明确情感描述的角色对
- 同一对角色保留最终状态，历史变化写入演变轨迹
- 关注关系转折的精确位置和触发原因

#### B. 开头分析

- 前 3 句原文引用
- 前 50 字分析：有没有冲突/异常？
- 前 100 字分析：读者是否知道核心矛盾？
- 钩子类型：悬念/冲突/反差/代入/信息差
- 开头情绪强度（1-10）
- 代入感评估：强（读者立刻在意主角遭遇）/ 中（需要几段才能投入）/ 弱（缺乏共鸣点）
- 信息密度评估

#### C. 结尾分析

- 最后一段原文引用或概括
- 结尾类型：HE满足/BE遗憾/开放式/反转余韵/留白
- 结尾情绪强度（1-10，虐文≥8、爽文≥7、治愈文≥6为合格）
- 情绪落点
- 余韵设计（读者离开时在想什么）
- 传播欲（读者会不会想转发/推荐）
- 收束完整性（所有钩子是否回收）

#### D. 首尾呼应分析

对比开头和结尾的元素呼应：

| 呼应元素 | 开头位置 | 结尾位置 | 呼应方式 | 效果 |
|----------|----------|----------|----------|------|
| {元素} | {如：第1节"私生子而已"} | {如：结尾终身未娶} | {对比/反转/升级} | {形成闭环/制造遗憾} |

#### E. 钩子回收检查

列出全文埋设的所有钩子及其回收状态：

| 钩子 | 埋设位置 | 类型 | 回收位置 | 回收方式 | 状态 |
|------|----------|------|----------|----------|------|
| {钩子描述} | {节N} | {悬念/冲突/信息差} | {节M} | {如何回收} | {已回收/未回收/开放式} |

未回收的钩子标注为「留白」或「遗漏」。留白需分析是否为刻意设计；遗漏需指出问题。

### Phase 6：汇总报告

综合所有阶段数据，输出拆文报告。包含：
- 一句话评价（成功核心原因）
- 五维评分（开头吸引力、情绪拉扯力、反转设计、节奏控制、结尾余韵）
- 核心技法总结
- 可借鉴结构（至少 3 条，含适用场景）
- 同类型写作建议

### 可选模块：同类对比

将分析对象与同题材、同结构的其他作品对比：

| 维度 | 本文 | 对标作品A | 对标作品B |
|------|------|----------|----------|
| 情绪曲线形态 | {如：压缩弹簧} | {如：V形} | {如：波浪} |
| 核心技法 | {如：假死+信息差} | {如：时间线反转} | {如：套娃反转} |
| 开头钩子强度 | {1-5} | {1-5} | {1-5} |
| 反转惊喜度 | {1-5} | {1-5} | {1-5} |
| 结尾余韵 | {1-5} | {1-5} | {1-5} |

**差异化亮点**：本文与同类作品的关键差异是什么？这个差异是优势还是劣势？

### 可选模块：平台适配评估

评估该文在不同短篇平台的适配度：

| 平台 | 适配度 | 原因 | 建议调整 |
|------|--------|------|----------|
| 知乎盐言 | {高/中/低} | {原因} | {如有} |
| 番茄短篇 | {高/中/低} | {原因} | {如有} |
| 七猫短篇 | {高/中/低} | {原因} | {如有} |

平台评分参考：
- 知乎盐言：偏重文笔和情感深度，8000-12000字，第一人称有优势
- 番茄短篇：偏重节奏和爽感，5000-10000字，反转和打脸有优势
- 七猫短篇：偏重故事完整性和可读性，6000-12000字，结构清晰有优势

## 节拍提取规则

### 节拍类型（6 种，不得自创）

| 类型 | 定义 | 识别特征 |
|------|------|----------|
| 情绪节拍 | 角色内在情绪发生明显转变 | 情绪词、行为变化、内心独白 |
| 信息节拍 | 新信息被释放（读者或角色获得新认知） | 揭示、发现、被告知 |
| 冲突节拍 | 人物间产生正面对抗 | 直接对抗、拒绝、威胁 |
| 转折节拍 | 故事方向发生偏转 | 剧情方向改变 |
| 对话节拍 | 包含关键信息的对话或潜台词 | 对话中传递新信息或改变关系 |
| 氛围节拍 | 环境/氛围的重大转变 | 场景切换、时间跳跃、季节变化 |

### 核心质量铁律

1. **客观白描**：只记录"发生了什么"，禁止主观评价
   - 禁止：「沈暮月心碎地听到了真相」
   - 正确：「沈暮月听到"私生子而已"，手停在半空」
2. **绝对时序**：严格按文本中事件出现顺序排列
3. **情绪标记精确**：每个节拍标注情绪类型和强度值
4. **信息保真**：不遗漏改变上下文的关键细节
5. **高度浓缩**：一个节拍一句话概括
6. **复合合并**：为同一情绪/叙事目的服务的连续微动作合并为一个节拍

### 客观白描 vs 叙事框架词

- 禁止：「通过这段对话展现了她的坚强」
- 正确：「她直视霍庭煜说"我没有义务配合你"」
- 禁止：「气氛变得紧张」
- 正确：「霍庭煜眼神骤冷，周身散发出威压」

## 技法分析框架

### POV 策略分析

| POV 类型 | 效果 | 适用情绪 |
|----------|------|----------|
| 第一人称 | 亲密感、代入感强、可操控信息 | 虐恋、自省、内心戏 |
| 第三人称限制 | 兼顾代入和观察距离 | 通用 |
| 第三人称全知 | 上帝视角、多线并进 | 群像、悬疑 |
| 第二人称 | 极度沉浸 | 实验性、心理恐怖 |
| 非人视角 | 新奇感、陌生化 | 系统/鬼/动物视角 |

分析要点：
- 选择这个 POV 的好处和代价
- 有没有 POV 内的信息操控（如不可靠叙述者）
- POV 切换（如有）的时机和效果

### 对话技法分析

| 指标 | 计算方式 | 说明 |
|------|----------|------|
| 对话占比 | 对话字数 / 全文字数 | 短篇标准 45-65% |
| 潜台词率 | 含潜台词对话条数 / 总对话条数 | 高手 > 60% |
| 审判式对话 | 主角提问→对方自爆的数量 | 至少 2 处 |
| 信息差对话 | 读者知道但角色不知道的对话 | 虐文/反转文核心 |
| 伤人性对话占比 | 伤人台词 / 总对话条数 | 虐文 35-45%，爽文 20-30% |

**对话模式识别**：
- 审判式：主角提问 → 对方被迫自爆
- 压制式：短句碾压 → 对方歇斯底里
- 信息差式：双方信息不对称，读者在中间
- 推拉式：靠近又推开，反复循环

### 时间操控分析

| 技法 | 定义 | 识别特征 |
|------|------|----------|
| 时间跳跃 | 跳过一段时间 | 「三年后」「五年后」 |
| 场景压缩 | 用几句话概括长时间 | 概述性段落 |
| 平行剪辑 | 两条时间线交替 | A线/B线交替出现 |
| 倒叙 | 先说结果再说过程 | 结果先行，回溯原因 |
| 闪回 | 穿插回忆片段 | 突然插入过去场景 |
| 实时展开 | 逐秒展开关键时刻 | 关键场景慢动作 |

分析要点：时间操控的目的是什么（制造信息差、压缩无聊段落、制造对比）。

### 信息控制分析

追踪全文的信息分布：

| 时刻 | 读者知道的 | 角色A知道的 | 角色B知道的 | 信息差来源 |
|------|-----------|-----------|-----------|-----------|
| 开头 | ... | ... | ... | ... |
| 反转前 | ... | ... | ... | ... |
| 反转后 | ... | ... | ... | ... |

关键问题：信息差是否被有效利用来制造张力？

### 句式节奏分析

- 统计段落长度分布（短段 <30字、中段 30-80字、长段 >80字）
- 关键场景的句式变化（紧张时短句密集，舒缓时长句铺陈）
- 高潮位置的句式特征
- 「金句」位置（独立成段的短句）

### 对比锚点

识别文中的对比设计：
- 角色对比（主角 vs 对手的言行差异）
- 前后对比（同一角色/场景在不同时间的变化）
- 环境对比（奢华 vs 清贫、热闹 vs 冷清）
- 台词对比（同样的话由不同人说，或同一人不同时候说）

### 意象/物件追踪

追踪重复出现的物件或意象：

| 物件/意象 | 出现位置 | 每次承载的含义 | 演变轨迹 |
|-----------|---------|---------------|---------|
| {物件} | {节1, 节5, 节9} | {含义变化} | {从A到B} |

### 留白技法

识别作者刻意不写的内容：
- 省略的背景（留给读者想象）
- 未说出口的话（对话中的停顿/省略号）
- 跳过的过程（直接给结果）
- 留白的结尾（不交代后续）

## 情绪架构分析

### 情绪类型分类

| 类型 | 定义 | 信号词 |
|------|------|--------|
| 心疼 | 对角色遭遇的同情 | 行为细节、隐忍描写 |
| 愤怒 | 对不公的愤怒 | 反派行为、不公待遇 |
| 震惊 | 认知被颠覆 | 反转、真相揭示 |
| 满足 | 期待被回应 | 爽点释放、恶人受罚 |
| 紧张 | 担心后续发展 | 悬念、危机 |
| 心酸 | 复杂的苦涩感 | 放手、遗憾、成长 |
| 治愈 | 温暖的正面情绪 | 关怀、团聚、被理解 |
| 压抑 | 情绪无处宣泄 | 委曲求全、隐忍 |

### 情绪强度量表

| 值 | 对应 | 描述 |
|----|------|------|
| +9 | 极致爽感 | 打脸、碾压、终极反转、恶人伏法 |
| +7 | 强烈满足 | 关键证据揭露、期待满足 |
| +5 | 明显正面 | 小胜利、温情时刻 |
| +3 | 轻微正面 | 小进展、日常温馨 |
| 0 | 中性 | 过渡、铺垫 |
| -3 | 轻微不适 | 小挫折、小委屈 |
| -5 | 明显负面 | 被羞辱、被误解、被威胁 |
| -7 | 强烈虐感 | 被抛弃、被背叛、孩子受委屈 |
| -9 | 极致虐感 | 生死威胁、灵魂碾压、信仰崩塌 |

### 情绪曲线形态

| 形态 | 特征 | 适用题材 | 典型效果 |
|------|------|----------|----------|
| V形 | 先虐后爽 | 打脸/复仇 | 极致反差 |
| 倒V | 先甜后虐 | BE虐文 | 遗憾意难平 |
| 波浪 | 正负交替 | 追妻火葬场 | 情绪拉扯 |
| 阶梯上升 | 逐步升级 | 爽文/打脸 | 节奏感强 |
| 断崖下跌 | 突然反转 | 死人文学/反转 | 震惊 |
| 压缩弹簧 | 长期压抑后一次释放 | 隐忍布局 | 极致释放 |
| 双峰 | 两个高潮 | 复杂短篇 | 层次丰富 |

## 节奏密度分析

### 四维密度指标

| 维度 | 计算方式 | 标准范围 | 说明 |
|------|----------|----------|------|
| 事件密度 | 节拍数 / 全文字数 × 1000 | 3-6 个/千字 | 太低=水，太高=赶 |
| 对话密度 | 对话字数 / 全文字数 × 100% | 45-65% | 短篇偏对话驱动 |
| 冲突密度 | 冲突节拍数 / 总节拍数 × 100% | 30-50% | 低于20%=太平，高于60%=疲劳 |
| 信息密度 | 信息节拍数 / 总节拍数 × 100% | 20-35% | 太低=无聊，太高=消化不及 |

### 节奏分布图

逐节标注四维密度，形成节奏热力图：

| 节 | 字数 | 事件密度 | 对话占比 | 冲突占比 | 节奏判断 |
|----|------|----------|----------|----------|----------|
| 1 | {N} | {X/千字} | {Y%} | {Z%} | {快/中/慢/过渡} |

### 节奏异常检测

| 异常模式 | 检测条件 | 问题 |
|----------|----------|------|
| 节奏塌陷 | 连续2节冲突密度<15% | 读者可能弃文 |
| 冲突过载 | 连续3节冲突密度>60% | 情绪疲劳 |
| 信息洪峰 | 单节信息节拍>50% | 读者消化不及 |
| 对话荒漠 | 连续2节对话<20% | 文本偏干 |
| 对话泛滥 | 单节对话>80% | 碎片化 |

## 角色提取规则

### 提取标准（短篇特化）

短篇角色精简，但必须提取所有有名有姓或有叙事功能的角色。

**必须提取**：
- 有名字（≥2字符）且有台词或推动剧情的角色
- 虽无明确名字但反复出现（≥2节）且承担叙事功能的角色

**不提取**：
- 群体称呼（"旁人""大家"）
- 无名路人（"一个中年人""助理"——除非有关键台词）
- 通用称呼黑名单：同长篇 chapter-extractor 的黑名单（老师、老板、师傅等）

### 角色功能标签（短篇特有，6 种）

| 标签 | 定义 | 示例 |
|------|------|------|
| 情绪承载者 | 承载读者共情的主要载体 | 沈暮月（第一人称主角） |
| 压迫源 | 制造负面情绪的角色 | 霍庭煜（冷漠/控制） |
| 反转触发器 | 触发关键反转的角色 | 霍宁（绑架事件） |
| 道德锚点 | 代表正常价值观的角色 | 杨姨（关心/担忧） |
| 对照组 | 与主角形成对比的角色 | 徐宇（温和 vs 霍的冷酷） |
| 催化剂 | 推动剧情但不直接参与核心冲突 | 徐阿姨（连接/温暖） |

一个角色可以有多个标签。

### 角色内在矛盾提取

短篇角色的核心在于内在矛盾，不是外部遭遇：

| 错误 | 正确 |
|------|------|
| 她被霍庭煜抛弃了（外部遭遇） | 她渴望被爱但学会了在不爱中生存（内在矛盾） |
| 他对她不好（行为描述） | 他习惯了掌控一切却无法掌控自己的感情（内在矛盾） |

### 角色经济性评估

短篇每个角色都必须"物尽其用"。评估标准：

| 指标 | 问题 |
|------|------|
| 出场效率 | 第一次出场就完成角色定位了吗？ |
| 功能密度 | 一个角色承担了多少叙事功能？ |
| 可删除性 | 删掉这个角色，故事还成立吗？（不成立=好，成立=多余） |
| 对话贡献 | 该角色的对话是否每次都推动剧情或情绪？ |

## 结构模式匹配

### 11 种短篇结构

将分析对象与已知结构模式匹配，评估契合度和创新点：

| 结构 | 特点 | 适合情绪 |
|------|------|----------|
| 三幕反转式 | 铺垫→升级→反转 | 震惊、意难平 |
| 双线交叉式 | 明线暗线交替推进 | 悬疑、真相揭晓 |
| 时间跳跃式 | 过去/现在穿插 | 遗憾、成长 |
| 套娃反转式 | 多层反转嵌套 | 惊讶、烧脑 |
| 对话驱动式 | 通过对话推进叙事 | 虐恋、人际冲突 |
| 独白式 | 第一人称内心独白 | 治愈、自省 |
| 重生反常式 | 重生后做相反的事→对手自乱 | 爽、解气 |
| 灵魂旁观式 | 死后灵魂看世界→揭露真相 | 意难平、愤怒 |
| 双重生博弈式 | 两人都重生→信息战 | 紧张、痛快 |
| 隐忍布局式 | 表面顺从暗中布局→反攻 | 压抑→极致释放 |
| 非人视角式 | 鬼/系统/灵魂看人间 | 新奇、恐怖、爽 |

### 匹配分析要点

1. **主结构识别**：该文主要使用了哪种结构？
2. **混合结构**：是否混合了多种结构？混合比例如何？
3. **结构创新**：有没有对标准结构的创新使用？
4. **结构适配度**：这个结构是否最适合这个题材和情绪目标？

## 质量阈值体系

### 拆解完整性检查

| 指标 | 阈值 | 计算 | 不达标处理 |
|------|------|------|------------|
| 节拍覆盖率 | ≥90% | 有明确功能的节拍数 / 总节拍数 | <90% 检查遗漏 |
| 情绪曲线完整度 | 100% | 每个节拍都有情绪标记 | 补充缺失标记 |
| 技法识别数 | ≥5项 | 识别出的技法维度的数量 | <5 项深入分析 |
| 对话分析覆盖 | ≥80% | 已分析的对话条数 / 总对话条数 | <80% 补充分析 |
| 角色提取完整 | 100% | 有名角色全部提取 | 补充遗漏角色 |

### 拆文报告质量检查

| 检查项 | 标准 |
|--------|------|
| 一句话评价 | 不是泛泛赞美，是具体指出成功机制 |
| 五维评分 | 每项有具体说明（非"写得很好"） |
| 可借鉴结构 | 至少 3 条，每条含技法名+用法+适用场景 |
| 同类型写作建议 | 具体行动，不是"多练习" |
