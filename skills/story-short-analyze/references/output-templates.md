# 短篇拆文输出模板

> 拆文输出时加载。先看决策路由选 Phase，再按模板填写。方法论细节见 material-decomposition.md。

## 决策路由

| 你在执行哪个 Phase | 加载哪个模板 | 必填字段 |
|---------------|-------------|---------|
| Phase 1 确认对象 | 无模板（用户交互，见 SKILL.md） | 用户已提供文本+拆解方向 |
| Phase 2 结构+节拍 | Phase 2 全篇结构 + Phase 2B 节拍 | 至少 4 段结构 + 节拍覆盖全文 |
| Phase 3 情绪架构 | Phase 3 情绪曲线 + 情绪炸弹 | 至少 5 节点 + 炸弹 6 组件 |
| Phase 4 反转+技法 | Phase 4 反转分析 + 技法分析 | 前置反转检查 + 铺垫线索 ≥2 + 技法 ≥5 项 |
| Phase 5 角色+首尾 | Phase 5 角色 + 开头/结尾 | 所有有名角色 + 前 3 句引用 + 结尾类型 |
| Phase 6 拆文报告 | Phase 6 拆文报告 | 五维评分 + ≥3 条可借鉴结构 |
| 同类对比（可选） | 同类对比 | 差异化亮点 |
| 平台适配（可选） | 平台适配评估 | 三平台适配度 |
| 节奏密度（可选） | 节奏密度分析 | 四维密度指标 + 节奏异常检测 |

## Phase 2B 节拍提取

> 方法论详见 material-decomposition.md「节拍提取规则」。

### 密度指引

| 全文字数 | 目标节拍数 |
|----------|-----------|
| ≤5000 | 15-25 |
| 5000-8000 | 25-40 |
| 8000-12000 | 35-55 |
| >12000 | 45-60 |

### 节拍模板

```markdown
B{序号} **{事件概括}**：类型{情绪/信息/冲突/转折/对话/氛围} | 情绪{类型}{强度-9~+9} | 涉及{全名} | 技法{如有时}

原文引用（≤300字）
```

### 输出示例

```markdown
## 节拍清单

B1 **偷听到对话**：类型{信息} | 情绪{震惊}{-7} | 涉及{沈暮月} | 技法{信息差}

> "霍总还不打算让沈暮月母子进门吗？"
> "没必要，私生子而已。"
> 我正准备推门而入，听到这话，手停在了半空。

B2 **自我认知**：类型{转折} | 情绪{心酸}{-5} | 涉及{沈暮月}

> 我是沈家的私生女，生了个儿子，也是私生子。
> 霍庭煜对我没有爱。
> 我默然抽回了手。
```

### 质量自检

- [ ] 节拍数量在密度指引范围内
- [ ] 每个节拍有客观白描（无叙事框架词、无主观评价）
- [ ] 每个节拍有情绪标记（类型 + 强度值）
- [ ] 节拍严格按时序排列
- [ ] 原文引用 ≤300 字且连续

## Phase 3 情绪架构

### A. 情绪曲线

至少 max(5, 节数) 个节点，含字数位置，每个节点标注钩子类型：

| 位置 | 字数 | 节拍序号 | 情绪 | 强度与方向 | 触发事件 | 钩子类型 |
|------|------|----------|------|------------|----------|----------|
| 开头 | {X} | B{N} | {好奇/心酸/震惊} | {虐-9~爽+9} | {事件} | {悬念/冲突/反差/代入/信息差/无} |
| 低谷 | {X} | B{N} | {心疼/绝望/愤怒} | {虐-9~爽+9} | {事件} | {钩子类型} |
| 反转点 | {X} | B{N} | {震惊/心疼} | {虐-9~爽+9} | {事件} | {钩子类型} |
| 高潮 | {X} | B{N} | {情绪} | {虐-9~爽+9} | {事件} | {钩子类型} |
| 结尾 | {X} | B{N} | {满足/意难平/治愈} | {虐-9~爽+9} | {事件} | {钩子类型} |

钩子类型速查：悬念（想知道后续）、冲突（矛盾激化）、反差（认知颠覆）、代入（感同身受）、信息差（读者知道角色不知道）

曲线特征：起始{...} | 走向{上行/下行/波浪/V形/倒V/阶梯/断崖/压缩弹簧} | 极值{最高%X 最低%Y} | 方向差{从X到Y} | 翻转次数{N}

### B. 情绪炸弹分析

| 组件 | 分析 |
|------|------|
| 引信 | {什么让读者开始在意}，前{X}字完成 |
| 火药 | {什么在积累情绪势能}，积累{X}字 |
| 延时装置 | {延迟引爆机制：信息差/误解/悬念} |
| 引爆点 | {哪个瞬间释放全部情绪}，精确到句子："{引用}" |
| 弹片 | {释放后的余波：角色反应} |
| 弹坑 | {情绪释放后留下什么，读者记住什么} |

### C. 期待管理追踪

逐节追踪读者的期待状态：

| 节 | 制造的期待 | 满足/升级/悬置 | 剩余期待 |
|----|-----------|---------------|---------|
| 1 | {期待A} | {制造} | {A} |
| 2 | {期待B} | {升级A} | {A+, B} |
| ... | | | |

期待管理规则：「两长一短不断」——不超过两节不制造新期待，不超过一节不推进核心期待。
