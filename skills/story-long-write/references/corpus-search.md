# 语料库检索指南

> 本文件指导写作过程中从 `拆文库/` 检索相似范本，为当前章节找到可借鉴的写作模块。

---

## 语料库结构

项目根目录 `拆文库/` 是统一语料库，每本拆解过的书形成一个子目录：

```
拆文库/
├── 语料库索引.md              # 全库索引（自动生成/手动维护）
├── {书名A}/
│   ├── 原文/                  # 原文备份
│   ├── 概要.md                # 全书概要 + 章节索引
│   ├── 拆文报告.md            # 五维评分 + 可借鉴套路 + 写法技巧
│   ├── 文风.md                # 句长/标点/对话潜台词/情绪节奏
│   ├── 章节/                  # 每章摘要 + 深度拆解
│   ├── 角色/                  # 角色档案 + 关系
│   ├── 剧情/                  # 剧情线 + 故事线
│   └── 设定/                  # 世界观/力量体系/势力
└── {书名B}/
    └── ...
```

## 检索维度

写作时按以下维度从语料库中检索相似范本：

### 1. 题材结构标号

每本书按题材归类，使用结构标号便于快速定位：

| 标号前缀 | 题材 | 示例 |
|----------|------|------|
| `XH-` | 玄幻 | `XH-001` 盘龙 |
| `DS-` | 都市 | `DS-001` 某都市文 |
| `XX-` | 仙侠 | `XX-001` 某仙侠文 |
| `LS-` | 历史 | `LS-001` 某历史文 |
| `KH-` | 科幻 | `KH-001` 某科幻文 |
| `XY-` | 悬疑 | `XY-001` 某悬疑文 |
| `AQ-` | 言情 | `AQ-001` 某言情文 |
| `QT-` | 其他 | `QT-001` 其他题材 |

标号规则：`{题材前缀}{三位序号}`，序号按入库顺序递增。

### 2. 结构化语录检索

每本书的结构化语录分布在以下文件中：

| 语录类型 | 文件位置 | 检索关键词 |
|----------|----------|------------|
| 开篇钩子 | `拆文报告.md` → 可借鉴套路 | 钩子、开篇、开头 |
| 爽点设计 | `拆文报告.md` → 爽点密度 | 爽点、释放、铺垫 |
| 写法技巧 | `拆文报告.md` → 写法技巧 | 一笔两用、延迟揭示、视角欺骗 |
| 角色金句 | `章节/*_摘要.md` → 角色提及 | 角色名、对白 |
| 情绪高点 | `章节/*_摘要.md` → 基调标注 | 基调：紧张/热血/轻松/悲伤 |
| 文风锚点 | `文风.md` → 原文锚点 | few-shot、模仿片段 |

### 3. 模仿索引

模仿索引记录每本书中可复用的写作模式：

```
模仿索引条目格式：
- 模式名称：{如「反向开篇」}
- 出处：{书名} 第{N}章
- 原文片段：{300-500字原文锚点}
- 适用场景：{如「身世/血脉/天赋揭晓类开篇」}
- 抽象模板：{角色位抽象后的通用模板}
```

模仿索引从 `拆文报告.md` 的「可借鉴套路」和「写法技巧」两节提取。

## 写作时检索流程

### 长篇写作（Phase 4 单章写作 step 3.2 模块召回增强）

在现有模块召回流程基础上，增加语料库全局检索：

1. **确定本章需求**：目标情绪词 + 需要的技法类型（钩子/爽点/反转/对话/打斗等）
2. **读取语料库索引**：`拆文库/语料库索引.md`（如存在），快速定位相关题材的书目
3. **按题材匹配**：从索引中找到与当前项目同题材或相似题材的书目
4. **按技法匹配**：从各书的 `拆文报告.md` 中 grep 对应技法关键词
5. **按情绪匹配**：从各书的 `章节/*_摘要.md` 中 grep 目标情绪基调
6. **召回结果**：输出最多 5 条语料库召回结果，每条包含：
   - 书名 + 章节号
   - 匹配原因（题材相似/技法匹配/情绪一致）
   - 原文锚点片段（≤300字）
   - 可借鉴的具体技法说明

### 短篇写作（Phase 3 正文写作前）

1. **确定本节需求**：目标情绪 + 结构物件 + 反转类型
2. **从拆文库检索**：按情绪类型和反转类型在 `拆文库/` 中搜索相似范本
3. **读取情节节点**：从匹配书目的 `情节节点.md` 中找相似结构
4. **读取写作手法**：从匹配书目的 `写作手法.md` 中找可借鉴技法
5. **召回结果**：输出最多 3 条，每条包含书名 + 匹配段落 + 可借鉴技法

## 语料库索引维护

### 自动生成时机

- 每次 `/story-long-analyze` 或 `/story-short-analyze` 完成后，自动更新 `拆文库/语料库索引.md`
- 索引条目从各书的 `概要.md`（长篇）或 `拆文报告.md`（短篇）自动提取

### 索引条目格式

```markdown
## {书名}

| 字段 | 值 |
|------|-----|
| 标号 | {题材前缀}{序号} |
| 题材 | {具体题材分类} |
| 类型 | 长篇 / 短篇 |
| 总字数 | {N}万字 |
| 总章数 | {N}章 |
| 平台 | {起点/番茄/晋江/知乎等} |
| 核心梗 | {一句话核心梗概} |
| 核心情绪 | {主要交付的情绪} |
| 可借鉴点 | {1-3个最值得借鉴的技法} |
| 入库时间 | {YYYY-MM-DD} |
```

### 手动补充

用户也可以手动在 `拆文库/语料库索引.md` 中添加条目，格式同上。

| 「对话怎么写自然」 | 在拆文库中搜索对话相关的文风锚点 |

## 注意事项

1. **语料库是参考，不是模板**：检索到的范本用于启发思路，不做直接复制
2. **角色位抽象**：借鉴套路时做角色位抽象，用自己的角色填充
3. **情绪优先**：先匹配情绪目标，再匹配具体技法
4. **缺失不阻塞**：语料库为空或索引不存在时，跳过检索，不阻塞写作流程
